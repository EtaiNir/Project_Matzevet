# סיכומי פגישות (Meetings)

תיקייה זו מכילה **סיכומי פגישות** עם סבא (המשתמש/בעל הצורך) ועם איתי (המפתח שבנה את הפיילוט והפייתון).

כל פגישה מתועדת בקובץ נפרד, כדי לעקוב אחרי דרישות, החלטות, ומשימות שעלו.

## מבנה קובץ פגישה

קובץ חדש בשם: `YYYY-MM-DD-עם-מי.md` (לדוגמה: `2026-07-05-סבא.md`).

```markdown
# פגישה — YYYY-MM-DD

- **משתתפים:**
- **נושא:**

## מה עלה
- ...

## החלטות
- ...

## משימות (action items)
- [ ] משימה — אחראי — תאריך יעד
```
