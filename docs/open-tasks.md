## זכאות לבגרות

- [ ] **1. אחוז מהשכבה למצטיינת ולטק בתמונת המצב.** היום האחוז מוצג רק במסך
  המצטיינים ([BagrutHonors.tsx](../src/pages/bagrut/BagrutHonors.tsx)).
- [ ] **2. עוגה בתמונת המצב** — זכאות כללית, ומצטיינת וטק בתוכה.
- [ ] **3. "סטטוס מעודכן רכז".** לשונית לרכז הבגרויות עם כל השכבה, שבה הוא משנה
  "אין זכאות" ל"יש זכאות" ישירות, והסטטיסטיקות משקפות את השינוי.
  היום אפשר לערוך `status` רק תלמיד-תלמיד (מיגרציה 038); העריכה דורסת את
  הערך המקורי ונמחקת בסבב הבא.
  - ⚠️ **החלטה נדרשת:** סטטוס מקביל שנשמר לצד המקורי (שני מספרים — "לפי
    הניתוח" ו"מעודכן רכז"), או הרצה מחדש של T1 מהנתונים המתוקנים.
- [ ] **4. ה-PDF של יומן המעקב יכלול גם את "המצב והתוכנית"** (כולל ניתוח ה-AI)
  כרקע. היום [printLog.ts](../src/lib/printLog.ts) מדפיס רק את רשומות היומן.
