# החלטות (Decisions)

תיקייה זו מכילה **רשומות החלטה** (ADR — Architecture Decision Records) שמתקבלות תוך כדי הפיתוח.

כל החלטה משמעותית מתועדת בקובץ נפרד, כדי שנזכור בעתיד *מה* הוחלט, *מתי*, ו*למה*.

## מתי לכתוב החלטה

- בחירה בין שתי טכנולוגיות/גישות
- שינוי בארכיטקטורה או במבנה הנתונים
- כל החלטה שנרצה להבין בדיעבד למה התקבלה

## מבנה קובץ החלטה

קובץ חדש בשם: `NNNN-כותרת-קצרה.md` (לדוגמה: `0001-supabase-per-authority-tables.md`).

```markdown
# NNNN — כותרת ההחלטה

- **תאריך:** YYYY-MM-DD
- **סטטוס:** מוצע / מאושר / מבוטל / הוחלף ע"י NNNN

## הקשר
מה הבעיה או השאלה שדורשת החלטה?

## ההחלטה
מה הוחלט?

## חלופות שנשקלו
אילו אפשרויות אחרות נבחנו ולמה נדחו?

## השלכות
מה המשמעות של ההחלטה — חיובי ושלילי?
```
